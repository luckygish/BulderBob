# Булдер (Bulder)

Экономический симулятор строительной компании. Игрок берёт заказы, нанимает бригады,
закупает материалы и технику, проходит десять сезонов и конкурирует с тремя ИИ-компаниями.

Проект содержит две версии:

- **Браузерная** — самостоятельное SPA на TypeScript и Vite в `web/`. Это актуальная версия.
- **Godot** — исходный прототип на GDScript в `autoload/`, `data/`, `scenes/` и `ui/`.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```bash
cd web
npm install
npm run dev
```

Production-сборка:

```bash
cd web
npm run build
npm run preview
```

Готовые файлы появляются в `web/dist/`. Сохранение хранится в `localStorage`;
текущий формат — **версия 5**, старые версии 1–4 автоматически мигрируются.

## Основной цикл

1. Выберите обычный или особый заказ.
2. Соберите бригады, назначьте технику и купите комплект обеспечения для каждого объекта.
3. Зарезервируйте материалы через **«Закупить недостающее»**.
4. Запустите этапы и сдавайте объекты.
5. Реинвестируйте прибыль в кадры, технику, технологии и банковские инструменты.
6. Выполняйте цели десяти сезонов и программу развития.

## Программа развития

На странице **«Обзор»** доступна цепочка из 18 обучающих шагов. Она проводит игрока
через заказы, кадры, технику, склады, стройку, технологии, банк, продажу техники и особые
проекты. За каждый шаг один раз начисляется репутация.

## Компания

Раздел **«Компания»** позволяет:

- менять название компании;
- выбирать одну из пяти SVG-аватарок: дом, кран, каска, квартал, чертёж;
- видеть текущий деловой статус и прогресс до следующего.

Статус зависит от капитала:

| Капитал | Статус |
| ---: | --- |
| до 2,5 млн ₽ | ИЖС · Частный подряд |
| 2,5–5 млн ₽ | Местный застройщик |
| 5–10 млн ₽ | Региональный подрядчик |
| 10–18 млн ₽ | Городской девелопер |
| 18–30 млн ₽ | Федеральный застройщик |
| от 30 млн ₽ | Корпорация недвижимости |

## Сезоны

Каждый сезон длится 90 дней. Всего 10 сезонов, лето и зима чередуются. Цели включают
капитал, репутацию и число сданных объектов.

- Успешный сезон: **+5 репутации**.
- Проваленный сезон: **−15 репутации**.
- Следующий сезон начинается в любом случае.
- Активные проекты продолжаются, а сроки сдвигаются на −90 дней.
- Лето обычно повышает цену материалов, но продлевает рабочий день.
- Зима увеличивает трудоёмкость фундамента и эксплуатационные расходы.

## Технологии

В ветках 17 технологий:

- **Управление:** планирование до четырёх объектов и сезонное планирование;
- **Персонал:** обучение, ночной координатор, профстандарты и автоматизация;
- **Финансы:** банковский счёт, овердрафт, лизинг, дилерская сеть и факторинг.

Новые технологии:

| Технология | Эффект |
| --- | --- |
| Сезонное планирование | Все сезонные дебаффы ×0,8 |
| Ночной координатор | Ночной тариф ×0,85 |
| Овердрафт | Долг до 400 000 ₽ не блокирует работу, процент 1% в день |
| Дилерская сеть | Продажа собственной техники за 85% вместо 70% |

## Финансовый отчёт

После исследования **«Банковский счёт»** открывается вкладка **«Финансовый отчёт»**.
В ней без внешних библиотек строятся SVG-графики:

- динамика капитала и денег;
- динамика репутации;
- динамика цен на материалы;
- выручка и прибыль последних объектов;
- прибыль и маржа по типам объектов;
- структура затрат;
- статистика типов зданий;
- прогресс текущего сезона;
- ключевые показатели, долг, техника и лучший объект.

История хранит до 120 ежедневных срезов.

## Механики

### Материалы

У каждого проекта есть отдельный резерв. Быстрая закупка сразу выделяет партии за объектом,
поэтому материалы одного проекта не считаются доступными для другого. Остаток резерва
возвращается на общий склад после сдачи: если он не помещается в лимит склада, излишек
автоматически продаётся за 70% себестоимости.

### Склад

Купленное без привязки к объекту попадает на личный склад — вкладка **«Мой склад»** на рынке
рядом с базами «Север» и «Юг». Ёмкость — **1000 ед. каждого материала**.

- Покупка сверх свободного места отклоняется; поставки и возврат резерва сверх лимита
  продаются за **70% себестоимости** и зачисляются на счёт.
- Плата за хранение списывается ежедневно от себестоимости запаса: **1%** при занятости
  1–500 ед., **2%** при более чем 500 ед., **0** на пустом складе.
- Кнопки **«Пополнить недостающее»** и **«Пополнить»** переносят материалы со склада в резерв
  объекта без доставки: этапы расходуют сначала резерв, затем склад. Перенос освобождает
  складское место и снижает плату за хранение.

### Рабочие

Типы: разнорабочий, специалист и прораб. У работника не больше двух навыков.
Навыки влияют на скорость, материалы, зарплату, доставку, командный бонус и ночную работу.

### Техника

Каждая единица — отдельный экземпляр. Можно покупать несколько одинаковых единиц.

- Бетономешалка — допуск к фундаменту без бонуса.
- Трактор — фундамент +30%.
- Экскаватор — фундамент +45%.
- Манипулятор — стены +15%, отделка +10%.
- Кран — кровля +20%, монтаж +10%.

Собственную технику можно продать за 70% цены или за 85% после «Дилерской сети».

### Особые проекты

Каждые 3 дня с вероятностью **20%** может появиться один особый проект. Доступны
«Ангар», «Телевышка», «Апартаменты» и «Дом отдыха». Они ограничены по сроку, требуют
спецтехнику и дают повышенную награду репутации.

### Лицензии и контракты

Лицензии открывают крупные государственные контракты. Заказы с лицензий появляются на
доске наравне с обычными, как только лицензия изучена и достигнута нужная репутация:

- **Городская лицензия** (репутация 70, капитал 10 млн): парк и сквер, детский сад,
  школа, спорткомплекс, больница;
- **Областная лицензия** (репутация 80, капитал 15 млн): дороги, мост, торговые склады,
  ледовый дворец, ТЭЦ.

## Структура браузерной версии

```text
web/src/
  game/
    balance.ts       # базовые константы
    catalog.ts       # здания, материалы, навыки, техника, технологии
    seasons.ts       # десять сезонов и сезонные эффекты
    progression.ts   # обучающая цепочка
    engine.ts        # экономика, стройка, сезоны, боты
    actions.ts       # действия игрока
    selectors.ts     # прогнозы и статус компании
    persistence.ts   # сохранение и миграции v1-v4
  ui/
    app.ts
    dom.ts           # точечное обновление DOM
    components.ts    # общие компоненты и SVG-аватары
    pages/           # экраны, включая company и report
```
