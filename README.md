# Булдер (Bulder)

Экономический симулятор строительной компании. Игрок берёт заказы, нанимает бригады,
закупает материалы и технику, исследует технологии и конкурирует с тремя компаниями.

Проект содержит две версии:

- **Браузерная** — самостоятельное SPA на TypeScript и Vite в `web/`. Запускается без Godot,
  сохраняется локально в браузере. Это актуальная версия с расширенными механиками.
- **Godot** — исходная версия на GDScript, сохранена в `autoload/`, `data/`, `scenes/` и `ui/`.

## Запуск в браузере

Требуется Node.js 20.19+ или 22.12+.

```bash
cd web
npm install
npm run dev
```

Production-сборка и её локальный просмотр:

```bash
cd web
npm run build
npm run preview
```

Готовые файлы появятся в `web/dist/`. Серверная часть не нужна. Сохранение находится в
`localStorage`; при возврате на вкладку игра остаётся на паузе. Текущий формат сохранения —
версия 2, старая версия 1 автоматически мигрируется.

## Запуск Godot-версии

1. Установите Godot 4.
2. Откройте `project.godot`.
3. Запустите главную сцену `scenes/main.tscn`.

## Игровой цикл

1. Выберите обычный или особый заказ по бюджету, сроку, марже и требованиям.
2. Наймите до трёх работников в бригаду. Особые проекты требуют две бригады.
3. Купите, арендуйте или оформите в лизинг технику и назначьте конкретный экземпляр на объект.
4. Купите обеспечение. На каждый активный объект нужен отдельный комплект:
   бытовка, биотуалет, вода, генератор и ручной инструмент.
5. Нажмите **«Закупить недостающее»** — материалы сразу резервируются за выбранным объектом
   и не становятся доступными другому проекту. Отложенная поставка тоже придёт в его резерв.
6. Запустите отдельный этап или всю стройку. Последний этап сдаёт объект автоматически.
7. Просмотрите финансовый отчёт и реинвестируйте прибыль.

Цель сезона — за 90 дней получить капитал **10 000 000 ₽** и репутацию **70**.

## Управление и экраны

- **Пауза / Продолжить**, **×1 / ×2 / ×4** — 2 / 1 / 0,25 секунды на игровой час.
- **J** — журнал, **Escape** — закрыть диалог.
- **Обзор**, **Заказы**, **Строительство**, **Рынок**, **Кадры**, **Техника**, **Технологии**,
  **Банк**, **Конкуренты**.
- Интерфейс при обновлении не пересоздаёт всю страницу: изменяются только реально изменившиеся
  DOM-узлы. Это убирает мерцание и потерю нажатий во время игры.

## Механики браузерной версии

### Материалы и склады

- Общий склад компании и отдельный резерв каждого объекта.
- «Закупить недостающее» сразу выделяет партии за выбранным проектом.
- При обеспечении этапа сначала расходуется резерв проекта, затем общий склад.
- Остаток резерва возвращается на общий склад после сдачи объекта.

### Рабочие

Типы: разнорабочий (0.8), специалист (1.0), прораб (1.1 + командный бонус). Ставки и
сгенерированные навыки видны в карточке кандидата. У работника не больше двух навыков;
прораб не получает негативные эффекты.

Основные навыки:

- **Алкоголизм** −15% скорости; **Медлительный** −10%; **Трудяга** +20%.
- **Сова** разрешает ночную работу бригаде.
- **Вор** +5% к материалам; **Бережливый** −4%.
- **Наставник** +0.06 эффективности каждому члену бригады.
- **Логист** −5% к доставке объекта.
- **Технолог** +15% к бонусу техники.
- **Дорогой специалист** +15% к его ставке.

### Техника

Каждая единица — отдельный объект парка с уникальным назначением. Повторная покупка,
аренда и лизинг одного типа разрешены. Арендные часы расходуются только на объекте.

Бонусы этапов:

- бетономешалка — допуск к фундаменту без бонуса;
- трактор — фундамент +30%;
- экскаватор — фундамент +45%;
- манипулятор — стены +15%, отделка +10%;
- кран — кровля +20%, монтаж +10%.

Для обычных этапов после фундамента техника опциональна: без неё этап строится без бонуса.
На отдельных этапах особых проектов кран или другая указанная спецтехника обязательна.

### Особые проекты

Раз в 3 дня с вероятностью 10% на доске может появиться **«Ангар»** или **«Телевышка»**.
Особый заказ живёт 2–5 дней, требует двух непустых бригад и спецтехники, даёт высокий бюджет
и +8/+10 репутации при своевременной сдаче. Боты особые проекты не берут.

### Баланс

- Стартовый капитал: **2 000 000 ₽**, репутация **50**.
- Рабочий день: **08:00–18:00**; ночной тариф **×1,5**.
- Просрочка: **3% бюджета за день**, максимум **15%**.
- «База Север» — доставка сегодня, комиссия 2%; «База Юг» — завтра, комиссия 3,5%,
  стартовые цены на 6% ниже.
- Рынок пересчитывается каждые 3 дня в коридоре цен **0,8–1,35** от базовой.
- Лизинг: взнос 20%, переплата 12%, 30 дней; после выплаты техника становится собственной.
- Обслуживание своей и лизинговой техники: **0,1% цены в день**.
- Кредиты после «Банковского счёта»: 500 000 ₽ под 6% или 800 000 ₽ под 8%, 30 дней.
- Факторинг: аванс 30% бюджета, комиссия 2%.

Подробные формулы приведены в `FORMULAS.md`.

## Структура браузерной версии

```text
web/
  index.html
  src/
    main.ts
    styles.css
    game/
      balance.ts       # параметры времени, экономики и цели сезона
      catalog.ts       # здания, материалы, навыки, техника, технологии
      engine.ts        # время, стройка, рынок, складские резервы, боты
      actions.ts       # действия игрока и проверки условий
      selectors.ts     # прогнозы и производные показатели
      persistence.ts   # версионированное сохранение и миграция
      rng.ts           # воспроизводимый генератор случайных чисел
      types.ts
    ui/
      app.ts           # маршрутизация, обработчики и обновление экрана
      dom.ts           # точечное обновление DOM без полной перерисовки
      components.ts    # общие компоненты
      icons.ts         # SVG-иконки
      pages/           # экраны приложения
```
